# Container Search

Container Search mod is a mod that allows you to stay organized without the need for actual organizing, it indexes and keeps track of all container contents you open,
allowing you to easily find anything you need through one in game menu.

this mod requires only fabric api to function nothing else, and is currently only available for 1.21.4.
